# 如何下载远程仓库的代码到本地

- 使用 download-git-repo库下载远程仓库的代码到本地
  - 安装download-git-repo库
    ```bash
    npm install download-git-repo
    ```
    - 引入download-git-repo库
    ```javascript
    const download = require('download-git-repo');
    ```
    - 使用download-git-repo库下载远程仓库的代码到本地
    ```javascript
    download('github:username/repo-name', './xxxx', { clone: true }, err => {
      if (err) console.error(err);
      console.log('项目创建完成');
    });
    download('仓库地址','下载目标目录','配置选项','回调函数')
    配置选项：
  clone: true,        // 使用 git clone克隆 而不是直接下载
  shallow: true,      // 浅克隆（只下载最新提交）
  checkout: 'branch', // 指定检出的分支/标签
  force: true         // 强制覆盖已存在的目录
    ```
